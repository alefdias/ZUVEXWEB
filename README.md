# 🌐 ZUVEX WEB — Landing Page Oficial

Website oficial de divulgação e download direto do aplicativo **ZUVEX (Marketplace & E-Commerce Local)**, desenvolvido por **[Alef Dias](https://github.com/alefdias)**.

Hospedado via **GitHub Pages** em:
👉 **[https://alefdias.github.io/ZUVEXWEB/](https://alefdias.github.io/ZUVEXWEB/)**

---

## ⚡ Recursos do Website

* **Busca Dinâmica de Releases:** O script (`script.js`) consulta automaticamente a API do GitHub (`alefdias/ZUVEX`) em tempo real para obter o link direto de download do APK mais recente, versão e tamanho do arquivo.
* **Download com 1 Clique:** Baixa o arquivo `.apk` oficial direto do GitHub Releases sem redirecionamentos intermediários.
* **QR Code Inteligente:** Gera automaticamente na tela um QR Code apontando diretamente para o arquivo `.apk` da versão mais recente, facilitando o download direto pela câmera do celular.
* **Design Moderno (Vanilla CSS):** Dark mode premium com glassmorphism, gradientes e micro-interações sem dependências de frameworks pesados.
* **100% Responsivo:** Otimizado para smartphones, tablets e desktops.

## 🚀 Como Ativar o GitHub Pages

1. No repositório [https://github.com/alefdias/ZUVEXWEB](https://github.com/alefdias/ZUVEXWEB)
2. Acesse: **Settings** → **Pages**
3. Em **Branch**, selecione `main` e a pasta `/ (root)`
4. Clique em **Save**!
